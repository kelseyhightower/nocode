# برنامه‌نویسی بدون کد | هیچ‌کد

**امن‌ترین و قابل‌اعتمادترین راه ساخت نرم‌افزار این است که اصلاً نرم‌افزاری ننویسیم.**

نه کدی، نه خطایی، نه وابستگی‌ای، نه باگی؛ و البته نه محصولی برای نمایش.  
**هیچ‌چیز ننویس؛ هیچ‌جا منتشر نکن.**

> این پروژه یک شوخی و اثر طنز درباره‌ی دنیای برنامه‌نویسی است؛ نه یک ابزار نرم‌افزاری واقعی.

---

## فلسفه‌ی پروژه

ما به یک اصل ساده باور داریم:

- اگر کدی ننویسی، خطای نحوی هم نخواهی داشت.
- اگر وابستگی‌ای نصب نکنی، با ناسازگاری نسخه‌ها روبه‌رو نمی‌شوی.
- اگر چیزی نسازی، نیازی به نگه‌داری آن نداری.
- اگر چیزی منتشر نکنی، قطعی سرویس هم نخواهی داشت.
- اگر قابلیتی اضافه نکنی، هیچ‌کس نمی‌تواند درخواست حذف آن را ثبت کند!

**پیچیدگی، انتخابی است؛ هیچ‌کاری نکردن، یک سبک زندگی مهندسی است.**

## شروع سریع

برای شروع، ابتدا هیچ کاری انجام نده.

تبریک! پروژه‌ی تو از همین حالا در وضعیت اولیه قرار دارد.

## نصب و راه‌اندازی

این پروژه به نصب، تنظیمات، بسته‌ها، ابزارها یا محیط اجرایی نیاز ندارد.

دلیلش ساده است: چیزی برای نصب وجود ندارد.

## ساخت پروژه

برای ساخت برنامه، هیچ مرحله‌ای لازم نیست.

فرایند ساخت با موفقیت انجام شده است؛ چون چیزی وجود نداشته که ساخته نشود.

## انتشار

برای انتشار، مقصدی انتخاب نکن.

محصول تو با موفقیت به هیچ سروری منتقل نشده است.

## مقیاس‌پذیری

نگران افزایش کاربران نباش.  
ظرفیت این پروژه از نظر نظری نامحدود است؛ چون هیچ کاربری نمی‌تواند از قابلیتی استفاده کند که وجود ندارد.

## امنیت

سطح حمله‌ی نرم‌افزار با حذف نرم‌افزار به حداقل می‌رسد.

البته این به معنی امن بودن رایانه، حساب‌ها یا زیرساخت میزبان نیست؛ فقط خود این پروژه هیچ برنامه‌ی اجرایی ارائه نمی‌کند.

## مشارکت

مشارکت‌ها خوش‌آمدند، به شرط آنکه شامل کد نباشند.

برای جزئیات بیشتر، راهنمای [مشارکت](CONTRIBUTING.md) را بخوانید.

اگر باگی پیدا کردید، لطفاً توضیح دهید چطور چیزی که وجود ندارد توانسته خراب شود.

## استانداردها

برای آشنایی با اصول رسمی هیچ‌کد، [راهنمای سبک](STYLE.md) را مطالعه کنید.

## وضعیت پروژه

- زبان برنامه‌نویسی: هیچ‌کدام
- وابستگی: صفر
- فرایند ساخت: وجود ندارد
- محیط اجرا: تعریف نشده
- خروجی قابل اجرا: ندارد
- میزان کد اجرایی: صفر
